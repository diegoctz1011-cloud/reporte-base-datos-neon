# Producto 1 — Base de Datos en la Nube

Reporte académico integrador elaborado en HTML para la materia **Optativa I: Base de Datos en la Nube**.

## Ver el reporte

El archivo principal del sitio es:

- `index.html`

El reporte es autónomo: las imágenes y evidencias están incrustadas dentro del propio HTML, por lo que no necesita carpetas adicionales de recursos.

## Publicar con GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir **todos los archivos de esta carpeta** a la raíz del repositorio.
3. Entrar a **Settings > Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama **main** y la carpeta **/(root)**.
6. Guardar los cambios.

GitHub Pages publicará automáticamente `index.html` como página principal.
